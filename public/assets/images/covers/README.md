# Cover texture source

`white-nights.jpg` is an unmodified copy of the user-selected [Galaxia Gutenberg cover](https://www.galaxiagutenberg.com/wp-content/uploads/2025/05/Cub_Noches-blancas-115x180-1-990x1536.jpg), downloaded September 16, 2026.

The publisher URL remains the edition's `coverUrl`. The same-origin copy is used only as `coverTextureUrl`: the publisher's response lacks the CORS header required to load a cross-origin WebGL texture. Preserve the original artwork and 990 × 1536 proportions when replacing it.
